Questa sezione del repository raccoglie tutto l'occorrente per l'integrazione con Moon Cloud Driver.

Tutto ciò che si trova in questo folder è stato utilizzato per un repository esterno dedicato all'esecuzione dell'intero framework su MoonCloud.
Per ognuna delle 5 sezioni del documento CIS coperte dal framework, è stato creato un repository con queste caratteristiche.
È stata dunque adattata una sonda che fornisce i risultati dei controlli sulla singola sezione dando l'output in formato json secondo i criteri e vincoli della documentazione di Moon Cloud Driver.

In particolare come esempio qui vi è tutto ciò che è stato inserito per la sonda della sezione 2 App Service, di conseguenza le altre 4 sonde sono state replicate allo stesso modo.
